## 🚀 Ausgewähltes Projekt: Waffle-Pack-Bestücker (SMD)

Vollautomatisiertes Handhabungssystem zur Sortierung, optischen Prüfung und Verpackung von SMD-Präzisionswiderständen (Bauformen 0402, 0603, 0805) bei der SRT Resistor Technology GmbH:

* **Master-Steuerung:** Nicht-blockierender Zustandsautomat (C++) auf Arduino Mega 2560 R3
* **Positionierung:** Zweiachsige Linearführung mit PI Mercury Controllern im Closed-Loop über RS-232/TTL
* **Qualitätsprüfung:** Erkennung der Bauteillage via Omron Laser-Sensorik und Ausblasen per SMC-Magnetventil
* **Robustheit:** Autonome Fehlerbehandlung bei mechanischer Blockade ohne Verlust der Nullpunktreferenz
